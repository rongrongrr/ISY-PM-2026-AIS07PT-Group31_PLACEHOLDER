# Data

This directory contains everything related to how the CREMA-D dataset was obtained, prepared, and used for model training. It is split into two subdirectories:

| Directory | Purpose |
|-----------|---------|
| [`prep/`](prep/README.md) | Notebooks that reproduce the full data pipeline — cloning CREMA-D, splitting into train/test, and generating mel-spectrogram PNGs. |
| [`training/`](training/README.md) | Where the compiled dataset lives locally and where team members create their own training notebooks. |

See each directory's README for detailed instructions.
